# BTEC Quality Assurance Portal — demonstration

A static demonstration for St Ciaran's College. All sample activities are fictional. No authentication, server, or database is included. Changes are temporary and reset on page reload.

## Publish on GitHub Pages
1. Upload `index.html` to the root of the `btec-portal` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` and `/(root)` and save.
5. Open `https://mhughes925-mh.github.io/btec-portal/` after deployment.

## Security
This is a publicly accessible prototype. Do not enter real staff information, student records, confidential assessment records or passwords. A future operational version requires approved authentication, a database, server-side permissions, audit logs, backup and school data protection review.
